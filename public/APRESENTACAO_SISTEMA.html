STK CRM

Sistema de Gestão Comercial com Integração WhatsApp
Setembro 2026 — STK Tecnologia
💡 O que é o STK CRM?

O STK CRM é um sistema feito sob medida para gerenciar todo o ciclo de vendas de energia solar e RECIEE. Ele conecta WhatsApp, cadastro de clientes e controle de vendas em um único lugar.

Resumindo: Quando um cliente manda uma mensagem no WhatsApp, o vendedor já vê tudo sobre ele — dados pessoais, propostas anteriores, contas de luz, conversas — tudo na mesma tela.

🧩 Os 3 Módulos Principais
👥

Clientes

Cada cliente tem uma "pasta completa" com tudo que foi feito com ele — dados, propostas, contas de luz, conversas.

📋

Kanban

Quadro visual que mostra onde cada venda está. Funciona como um funil — cada venda passa por etapas até ser fechada.

💬

Atendimento

WhatsApp integrado — o vendedor conversa com clientes direto pelo sistema, sem precisar abrir o WhatsApp separado.

👥 1. CLIENTES — A "Pasta" do Cliente

Cada cliente tem uma pasta completa com 5 abas. Quando o vendedor clica num cliente, ele vê tudo sobre ele:

📄 Dados

Nome, telefone, CPF/CNPJ, endereço, concessionária, classe tarifária, consumo mensal com gráfico

⚡ GD

Todas as propostas de Geração Distribuída (solar), incluindo as feitas pela plataforma AXS

📊 RECIEE

Contas de luz enviadas pelo cliente, com análise automática de cobranças indevidas

💬 Atendimentos

Histórico de todas as conversas WhatsApp com o cliente

🎯 Oportunidades

Todas as oportunidades de venda vinculadas ao cliente

Por que isso é importante? Antes, cada informação ficava em um lugar diferente. Agora, tudo está na pasta do cliente. Se ele mandou 120 contas de luz para análise RECIEE, todas ficam salvas — e ocupam apenas ~24KB de espaço.

💬 3. ATENDIMENTO — WhatsApp Integrado

O módulo de atendimento é onde o vendedor conversa com os clientes diretamente pelo sistema, com 3 colunas no estilo WhatsApp:

📱

Lista de Conversas

Todas as conversas ativas, filtradas por número, com busca e etiquetas

💬

Chat

Conversa em tempo real com suporte a textos, imagens, áudios e documentos

👤

Painel do Cliente

Dados do cliente, propostas, e possibilidade de criar GD/RECIEE direto do chat

Destaques do atendimento:

Funcionalidade Como funciona
3 números de WhatsApp ROMA_2, STK-1 e STK-2 conectados ao mesmo sistema
Chatbot Inteligente Assiste virtual responde automaticamente as primeiras mensagens, qualificando o cliente com IA
Detecção de Conta Quando cliente manda foto/PDF da conta, o sistema sugere criar uma oportunidade
Criação de Propostas Vendedor pode criar propostas GD ou RECIEE direto do chat, sem sair da conversa
Etiquetas Classificar conversas (ex: "Prioridade", "Aguardando retorno")

⚙️ Tecnologia
Componente Tecnologia
Sistema Next.js 14 (hospedado na Vercel, plano gratuito)
Banco de dados Supabase (PostgreSQL, plano gratuito)
WhatsApp Evolution API (rodando num servidor próprio)
Chatbot Google Gemini 2.5 Flash (IA)
Análise de contas Tesseract.js (OCR gratuito, roda no navegador)
Propostas AXS Playwright (automação de navegador no servidor)

Custo de infraestrutura: Praticamente zero — tudo roda em planos gratuitos ou servidor próprio.

🎯 Resumo para Apresentação

"O STK CRM é um sistema que conecta WhatsApp, cadastro de clientes e controle de vendas em um só lugar. Quando um cliente manda mensagem, o vendedor já vê tudo sobre ele. Quando ele manda uma conta de luz, o sistema detecta e sugere criar uma oportunidade de venda. Tudo fica organizado num quadro visual que mostra onde cada venda está.
